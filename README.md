# Thermal Tracking

**熱感追蹤實驗台** — turn any video or photo into a thermal-camera look: false color, trails, glow, and live blob tracking.

Live: https://leo0047.github.io/thermal-tracking/

## Use

- Drop a video or image onto the page, or press **上傳素材**.
- Press **ROLL** for a random look, or switch to **PRO** for the full control panel.
- Drag effect stickers from **FX** onto the frame; stack up to four.
- Save a PNG or record six seconds of video from the buttons under the poster.

Everything runs locally in the browser with WebGL2. Nothing is uploaded.

## Run locally

It is a single file. Open `index.html` in a recent Chrome, Edge, Safari or Firefox, or serve the folder:

```sh
python3 -m http.server 8000
```
